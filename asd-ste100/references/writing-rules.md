# 规则与适用边界

本文件用中文概括上游 Skill 的规则分类，不复制 ASD 标准原文或批准词典。英文例句是语言分析对象，不是中文说明遗漏。

## 结构规则与词汇规则

结构规则可以直接检查句子形态。词汇规则依赖正式词典中词语的批准词义和词性。没有词典时，只能落实普通词汇、术语一致等原则，不能声称完成逐词合规检查。

| 分类 | 执行要求 | 核对边界 |
|---|---|---|
| 词义 | 同一概念使用同一名称，避免靠上下文猜测多义词 | 不同动作可以使用不同词；脚本的近义词提示不是语义证明 |
| 词性 | 注意名词和动词之间的角色变化 | 某个词是否获准作为特定词性使用，需查询正式词典 |
| 动作动词 | 优先用 `inspect`，少用 `perform an inspection` | 不声称替代动词一定属于批准词表 |
| 专业术语 | 保留必要术语；受众不熟悉时补充由原文或已确认材料支持的定义 | 不编造领域定义，不为了简化而替换代码标识符 |
| 主动语态 | 操作步骤明确执行主体和动作 | 执行者未知时保留未知；描述性文本可以保留必要被动语态 |
| 简单时态 | 在语义相同的前提下采用简单形式 | `has completed` 可能表达当前已完成；不得丢失这种状态意义 |
| 指令 | 一句一项指令，条件紧邻受影响动作 | `should` 不是 `must`，建议不能擅自升级为命令 |
| 句长 | 指令争取至多 20 个英文词，描述至多 25 个 | 精确条件和不确定性优先于句长 |
| 名词组合 | 优先把超过三个词的名词堆叠展开成明确关系 | 专有名称和必要领域术语需要单独判断 |
| 标点 | 避免分号，拆成句子 | 不一律禁止破折号；代码中的标点不属于改写范围 |
| 段落 | 一个主题，通常至多六句 | 不因形式阈值拆散读者必须一起理解的关系 |
| 列表 | 明确顺序、条件与并列关系 | 不把原文的任选项改成所有选项都必须执行 |

## 不确定性与要求强度

把作者的确信程度视为内容的一部分。优先保留以下区别：

| 原文表达 | 不得改成 |
|---|---|
| `may have failed` | `failed` |
| `could be caused by X` | `X is the cause` |
| `sometimes` | `always` 或没有频率限定的绝对陈述 |
| `should read the output` | `must read the output` 或更强的命令 |
| `tries to synchronize` | `synchronizes` |

可去掉没有增加信息的套话，但不能顺手删除同一句中的概率、范围、责任、条件或例外。原文没有证据说明频率时，不能增加“最常见原因”；原文只提示风险时，不能把新增检查步骤冒充原文改写。

若拆句需要补出主体或逻辑分支，先确认原文支持该关系。无法确定时保留条件原句，或向用户指出需要明确的含义。

## 结构脚本的实际覆盖

| 规则标识符 | 等级 | 覆盖与限制 |
|---|---|---|
| `semicolon` | 硬性 | 检查非代码文本中的分号 |
| `phrasal-verb` | 硬性 | 检查固定列表中的短语，不覆盖全部英文短语动词 |
| `marketing-adjective` | 硬性 | 提示固定列表中的宣传词，不判断证据或承诺是否真实 |
| `nominalization` | 硬性 | 检查部分“执行某种分析”式模式，不覆盖全部动作名词化 |
| `long-sentence` | 硬性 | 按空白计词，统一阈值 25；不完整解析缩写、跨行句子或 Markdown 链接 |
| `synonym-rotation` | 硬性 | 每文件检查固定词组；不判断词语在上下文中是否指同一动作 |
| `dangling-conjunction` | 硬性 | 检查所支持列表项末尾的 `and`、`or` |
| `passive-voice` | 建议性 | 使用正则启发式，存在误报和漏报 |
| `present-perfect` | 建议性 | 检查部分复合时态，保留情态动词表达的不确定性 |

“硬性”只决定脚本退出码，不表示发现一定正确。`--baseline` 和 `--disable` 用于已有文稿的逐步采用，不能用来证明语义或标准合规。
