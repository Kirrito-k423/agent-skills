DeepEP-Ascend 的 Dispatch 如何完成

把每个 token 送到需要它的 Rank，再在接收端为每个命中的专家生成一行输出。同一 token 对同一 Rank 只传一次，专家展开留到 copy epilogue。

01 · Python / Host检查输入，选择特化

EPBuffer.dispatch 接受 BF16 或 FP8 输入。Host 准备张量与通信指针，DeepJIT 编译对应模板。

02 · Dispatch / SIMT统计与路由去重

每个 AIV 负责连续 token 区间。专家计数逐 top-k 累加，Rank 计数按目标去重，分配接收槽和 SGE。

03 · Dispatch / Scalar打包元数据，提交发送

本机 hidden 经过 UB 复制；远端 SQE 直接引用输入 hidden 与 GM 元数据。准备完成后推进 SQ 并写 doorbell。

04 · Copy epilogue确认完成，按专家展开

drain 与跨 Rank barrier 建立消费边界，随后读取接收槽，计算专家内位置，写出 hidden、权重和来源元数据。

步骤 2 与 3 在同一个 kernel 内并行协作，通过 local_copy_ready 和 metadata_ready 握手；卡片编号表示阅读顺序。
