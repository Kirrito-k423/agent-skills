# 双屏联动与逐步高亮

实现共享状态、窗口恢复和红色高亮时使用本参考。关键是“一份模型、一份权威进度、两个视图”。

## 状态协议

同源 `BroadcastChannel` 适合在同设备、同浏览器配置文件中同步两个窗口。协议与页面链接携带同一个 session ID，不同演示会话相互隔离。源站、端口、浏览器配置文件或设备不同均不能假定相通；有跨设备需求时再选服务端方案。

建议状态包含：数据集与参数、当前阶段与步骤、播放状态、步长时间、时间锚点、选中记录、关注 rank，以及控制权和版本字段。示例字段为 `session / dataset / params / step / playing / duration / anchorStep / anchorTime / selected / focus / owner / epoch / revision`。

- **状态提交**：控制页是权威写入者；动画页的选中操作发回命令，由控制页统一更新状态，避免两个页面各自改进度。
- **后加入**：新窗口发 `hello` 请求，现有窗口提供完整快照。必须先安装监听器，再请求状态，避免错过回复。
- **刷新恢复**：动画页从控制页恢复；控制页单独刷新时可从仍存活窗口的缓存恢复。仅内存实现应说明关闭全部窗口后重置。
- **多控制页**：明确唯一 owner，避免两个定时器同时推进。通过租约或其他协调方式接管，并处理同时加入、旧 owner 恢复和后台降频。
- **消息排序**：用 epoch、revision 和确定的平局规则拒绝过期状态，接管不允许步骤回滚。命令必要时有 ID，防止重复应用。
- **链路状态**：分清已连接、等待控制页和失联。心跳不改变教学步骤，不重建整幅动画。

字段本身不会自动保证一致性，应实际验证多窗口同时启动、控制窗口刷新与接管。对于同源本地演示，无须引入数据库或把源码发送给第三方。

## 用同一时间锚点播放

不能让两个窗口分别用 `setInterval` 累加步骤。定时器只负责唤醒绘制，步骤由权威状态的同一时间锚点计算：

```text
elapsed = max(0, now - anchorTime)
step = min(lastStep, anchorStep + floor(elapsed / duration))
```

仅在 playing 时计算；暂停时显示冻结的 step。示例公式适用于同设备共享的墙上时钟；处理系统时间异常，或建立明确的共享时基。不同窗口的 `performance.now()` 原始值不能未经时基对齐直接互比。

暂停、调速和拖动先结算当前步骤，再提交新的状态与锚点。可以保留或重置一步内的剩余时间，但选择应一致。播放至终点后由权威状态停止。后台窗口恢复显示时重新按锚点推导，避免持续漂移。

绘制状态区分：模型或参数变化、教学步骤变化、选择变化、连接状态变化。只有新教学步骤触发进步动画；心跳和重复状态包不触发红色闪烁。

## 红色的语义

**红色表示本步实际发生的操作，包括读取、写入和执行；不等同于“数值不同了”。**

| 画面元素 | 何时红色高亮 |
|---|---|
| 源数组单元格 / 源块 | 本步读取该范围时 |
| 传输连线与目标标识 | 本步提交或完成的传输；文字注明具体含义 |
| 目的数组单元格 | 本步实际写入，包括 0、同值重写和新副本 |
| 小计 / base / prefix | 本步读取或产生该结果时，区分读与写 |
| 标志 | 本步等待检查、设置或清零时，标注对应动作 |
| 源码行 | 本步实际执行且与当前解释有关的关键语句 |

高亮使用模型给出的显式集合，不用页面前后文本差异猜操作。源码按语义事件映射到真实行号和条件；不要用宽泛的 `DataCopy` 正则把声明和未走分支一起染红。

rank 身份色保持稳定；已完成数据使用普通完成色；人工选中记录可用金色边框。红色边框、文字和淡底配合“读 / 写 / 等待”等标签，图例明确颜色含义。边框应预留空间或使用 outline，避免步骤变化导致布局跳动。

每步可轻闪一次，随后保留静态红色；下一步清理旧 active 集合，再应用新集合。暂停不移除红色。`prefers-reduced-motion` 关闭闪烁和大幅移动，但保留操作定位线索。

## 典型边界

- 多核同批执行：所有本步活动核的输入和输出同时红，不能只强调当前关注 rank 而暗示其他核没执行。
- 0 token 分支：实际填零语句红；未执行的原子累加不红。
- 只有一个计数核：初始 base 可标为当前结果，未执行的“前面核求和”分支不红。
- 串行累加：本轮 count 与新 prefix 同时红，前一轮 prefix 回普通完成状态。
- 发布副本：只强调本步产生的副本；此前副本保留但不持续冒充当前写入。
- 清旗后的快照：明确“读取前快照”和“本步结束已清零”，避免历史值造成有效性误解。
- 参数或数据集切换：重新生成模型，校正步骤上限并清理失效的选中 ID。

## 窗口与全屏

控制页提供用户点击触发的“打开动画屏”和两页链接，保留相同 session。全屏切换响应用户操作，并监听 `fullscreenchange` 更新按钮状态。用户将窗口拖到各显示器即可；默认不需要申请多屏布局权限。

同一进度条负责推进两页；动画页可以显示只读步号或进度提示，但不再加入一套独立播放时钟。弹窗被拦截时手动链接应仍可使用。通过同一本地 HTTP 服务打开模块页面，不能依赖 `file://` 的跨页通信表现。
