# 双层解释法

围绕用户指定的概念或问题，分别建立直观模型和专业模型，避免只留下“好像懂了”的感觉。

## 第一层：小白版

1. 使用日常语言解释核心意思，避免先堆术语。
2. 给出一个具体、贴切的例子或类比。
3. 说明这个概念解决什么问题，以及它最直观的工作方式。
4. 明确类比在哪些地方不再成立，避免用户把类比当成完整机制。

## 第二层：专业版

1. 使用该领域的准确术语重新解释。
2. 讲清核心机制、关键组成和因果关系。
3. 说明适用条件、边界条件和常见误解。
4. 如果存在多个主流定义或实现，指出差异，不强行合并。

## 完成输出

最后整理：

1. 小白说法与专业术语的对应关系。
2. 用户最容易理解错的地方。
3. 三个由浅入深、用于检查是否真正理解的问题。

除非用户明确要求，不要立即给出检查题答案；先让用户尝试回答，再根据回答纠正理解。
