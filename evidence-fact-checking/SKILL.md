# 事实核查

同时核查事实本身和从事实到结论的推理链。默认联网检索最新、可追溯的证据。

## 拆分待核查内容

先将用户提供的说法拆分为：

1. 可以被外部验证的事实。
2. 从事实推出的结论。
3. 其中包含的价值判断。

把复合说法拆成最小可核查单元，不要用一个标签覆盖多项不同可信度的主张。

## 核查事实

逐项检查来源、样本、统计口径、发生时间和完整上下文，并标记为：

1. **已证实。** 多项高质量证据直接支持。
2. **基本成立，但需要收窄。** 核心方向成立，但原说法范围、时间或强度过大。
3. **存在争议。** 可靠来源之间有实质冲突。
4. **证据不足。** 当前没有足够信息确认或否定。
5. **明显错误。** 高质量证据与说法直接矛盾。

优先使用官方资料、原始数据、论文和其他一手来源。引用重要证据时就近给出来源、日期及其直接支持的内容。

## 审查推理

在相关事实成立的假设下继续检查：

1. 这些事实能否推出当前结论。
2. 是否藏有未经验证的假设。
3. 是否混淆相关性与因果关系。
4. 是否遗漏其他解释或关键信息。
5. 结论在什么条件下成立或失效。

## 完成输出

最后总结：

1. 哪些事实可信，哪些需要修正。
2. 推理链中最关键的漏洞。
3. 补强后的最合理版本。
4. 用户目前可以相信到什么程度，以及仍需什么证据。

不得因为找不到证据就断言说法为假，也不得因为来源众多就忽视所有来源可能共同引用同一原始材料。
