# 第一性原理

从无法绕开的事实、目标和约束重新推导方案，不把“大家一直这样做”当成基本事实。

## 拆回底层

围绕用户的问题区分：

1. **基本事实：** 已经确认、无法绕开的客观条件或机制。
2. **未证假设：** 习惯性接受，但尚未验证或可以改变的前提。
3. **真实目标：** 用户最终希望实现的结果，而不是当前方案本身。
4. **资源与约束：** 时间、预算、能力、规则、风险承受力和不可牺牲条件。

对每个所谓“事实”追问其证据和可变性。不要把组织惯例、历史选择或现有技术实现误判为自然规律。

## 重新推导

1. 暂时放下行业惯例、现成方案和已有补丁。
2. 只从基本事实、真实目标和现实约束出发，列出必须满足的条件。
3. 推导一条或多条可行路径，并说明每一步如何由前述条件推出。
4. 比较新路径与原方案，指出真正改变了什么。

## 完成输出

最后输出：

1. 原方案中只在修补表面的部分。
2. 从基本事实重新推导出的新路径。
3. 新路径成立的前提。
4. 验证它的第一步。

第一性原理不等于忽略经验。把行业经验降级为可检验假设，在完成推导后再用现实证据校验新方案。
