# 区间带宽与组成

## 定义与证据

主单位用 **包/tick**。一个包是日志最小可观察单元，例如一个 flag 块，不能冒称真实网络报文。每个块只在首次观察为一时计一次，不重复统计复制事件。同一个显示 tick 的各核观察先合并；保留零增量检查，避免只留下有到达的时刻。

在当前筛选范围内，记去重后的测量点为 t₀、t₁……，累计首次就绪包数为 C(t)。每个区间 `(tᵢ₋₁,tᵢ]` 的观测吞吐为 `(C(tᵢ)−C(tᵢ₋₁))/(tᵢ−tᵢ₋₁)`。该值是对轮询观测的有限差分，不能据此断言包在该区间实际传输，也不能认为未新增观测时物理链路空闲。首测已有的包单独记账，不编造零时刻基线；首测前、末测后显示未知。单点或空输入无法计算速率。

默认排除 `group=-1` 本机复制。允许显式包含时，标题持续说明不全是网络流量。来源 rank 只改变归属维度，时间仍来自接收侧；按接收 rank 入口分别对齐的数据不能叫做物理上同时发生的全局带宽。真实发送时间、硬件计数器或时钟校准缺失时，禁止宣称实测链路利用率。

控制页允许配置：

- 每包 B：默认取模型 `blockBytes`，可改为用户需要的字节口径。
- 每 cycle μs：初始留空，用户输入后，按一个 tick 对应一个 cycle 换算。
- 纵轴：原始包/tick 或换算 GB/s；未配置 cycle 时长时禁用 GB/s。
- 参考上限：可选、与当前纵轴同单位。比值称为“参考比”，不能冒充实测利用率；改变单位或换算参数时清除旧上限。

采用十进制 `GB/s = 包/tick × B/包 ÷ (μs/cycle) ÷ 1000`。原始计数、tick、包/tick 不随配置改变。不要猜测设备频率，也不要把估算值写回原始模型。

## 图形与交互

两屏可切换流动网图、完成曲线、观测带宽，共享时间游标。带宽页并排绘制 group 组成和 rank 组成，两图各自叠加后都等于总吞吐，不能把两套分解相加。保留全部 rank 对统计的贡献；图例可摘要，但控制表必须包含该区间所有非零贡献者。

默认使用相邻观测点，另提供固定 tick 窗口抑制采样密度造成的尖峰。窗口以首测为起点，右端闭合；末尾使用真实剩余时长，不能拿完整窗口宽度作分母。通用实现最多生成 20 万个窗口，超限时放大窗口并明确显示实际宽度。

超过屏幕像素分辨率时，只在显示层按重叠时长加权汇总，保持面积与组成；同时保留原区间峰值包络，清楚标明均值与峰值。不要随机抽样或把窄峰丢掉。背景缓存，播放只重画游标。支持点击图定位原始区间、前后区间、游标附近放大和全程恢复；详情显示精确起止、Δ包、Δtick、包/tick、换算值和贡献百分比。

完整曲线用于复盘，显示当前游标之后的观测；“当前区间”对应游标所在的差分区间，并非运行时在线测量器。

CSV 用 `decomposition=total/groups/ranks` 明确区分总量与两套构成，`member` 指定 group/rank。`total` 保留零增量区间；首测基线在页面单独列出，不作为速率区间。三类记录不能一起求和。保留原始时间、包数、包/tick、用户换算参数及换算 GB/s。

## 验证

对不同 launch、接收/来源 rank、group/rank 筛选、本机复制开关、相邻与固定窗口分别验证：

1. `首测包数 + Σ(区间速率 × Δtick) = 当前范围观测到的总包数`。
2. 每区间 `Σgroup 包数 = Σrank 包数 = 总包数`。
3. 首测前和末测后未知；有两个测量点但无新增包时允许零值。
4. 重复位图、复制完成记录、零 token 任务不引入额外包。
5. 像素聚合保留积分与峰值；原始详情和导出不使用像素聚合值。
6. 换算线性且双屏一致；清空时钟输入恢复原始单位。刷新恢复配置，切 launch 重新计算并清除旧放大范围。

测试应包含独立手算的小例子以及真实模型的逐块复算，而不是仅仅重跑同一个聚合器。
