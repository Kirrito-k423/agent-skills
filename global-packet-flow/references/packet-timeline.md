# 双端聚焦与原子信包时序

## 共同筛选范围

来源 rank 与目的 rank 分别控制网图左右侧的可见 rank 集合。两侧独立重新排布，范围外对象移出画面；每个可见 rank 仍保留全部核与无任务状态。原有连线合并预算只控制展示，不影响统计。

点击发送核收窄来源，点击接收核收窄目的，保留另一端和 group 条件。详情任务列表只允许当前筛选内的来源任务，保留零 token 任务；找不到关联任务时不能偷偷替换为其它核的任务。改变筛选时优先保留仍有效的选择，否则定位范围内有效任务。清除筛选恢复全量对象。

## 时序图门槛和行定义

行数等于所选来源集合与目的集合的笛卡尔积，不以观察到事件的组合数替代，避免吞掉零任务或缺失组合。**≤512 行**自动显示时序预览，并允许展开；大于 512 时说明需要继续筛选，不抽取前 512 行冒充全量。当前单选筛选器在 64 rank 数据中对应 4096、64 或 1 行；算法测试须覆盖正好 512 与超过 512。

每行固定表示 `来源 rank → 目的 rank`。支持发送端优先或接收端优先排序、组合分页。网图下的紧凑预览每页 8 行；展开后可选 8/16/32 行。页数和显示范围必须可见，所有组合都可到达。无有效任务显示“无有效任务”，与应到但缺少完成时间分开。

## 原子身份与时间

位图观测模型中的原子包身份是 `launch / task / slot / block`，一包对应一个 flag 块。task 关联真实 src/dst、接收 AIV、localExpert 与推导发送 AIV。一个观察记录可以包含多个包，同 tick 多包不能合成一个事件计数。位图重复检查和复制完成不能再次生成新包。

现有模型的横轴采用每个包**首次就绪检查的 end**。未来日志若记录真实发送时间，应扩展模型并明确区分发送、首次就绪、复制三个时刻；禁止用当前 end 伪造发送起点或在途延迟。按接收 rank 各自入口对齐的坐标不是校准后的跨卡物理时间。

完整日志复盘中，点在游标之前（含当前 tick）显示绿色完成，之后显示灰色尚未到时。这里完成指已观察到 flag 就绪，不等于复制完成或真实链路完成。倒退用同一阈值重新查询，切 launch 必须重建，不能保留上一轮完成状态。应到但没有首次一的包只列未知数量，不编造横坐标。

## 重合与证据钻取

每个原子包都参与绘制和完成计数。相同时间的点可在所属行内垂直微错开，不能伪造横轴时间；像素重合时要明确说明。点击重合位置，在控制页展开其全部包，可分页但不可抽样。清单至少包括原子身份、当前状态、group、两端 AIV、首次检查区间、record 与原始行号。

点击清单中的任意包同步选择 task、slot、block、接收核和精确整数 tick；详情显示该块的观察证据。点击行名可进一步聚焦该来源目的对。共享排序、页号、时间范围、选中位置和清单页号；浏览器刷新和另一屏要能恢复。

## 验证

- 64×64 清除筛选时 7168 核；1×64 或 64×1 时 3640 核；1×1 时 112 核（56 核/rank 数据）。模型规模不同时按实际参数计算，不能写死。
- 单独按来源或目的枚举完整原子包，核对总量与完整未筛选模型一致。
- 核对每个点身份和最早的 record/line，不仅核对汇总包数。
- 同 tick 多包、缺失包、零任务、跨 launch、筛选变化、倒退、分页均有明确状态。
- 双屏点击与所有表格、详情始终遵守同一筛选范围。
