# 时间完成度曲线与关键节点

## 统计定义

对一个确定的 launch、过滤范围、group 和 rank，分母是应到块数：有效 token 数乘每 token 块数。分子是截至时刻 t 首次被观察为 1 的唯一块数。相同块在连续轮询中重复出现、后续复制完成，都不能再次计入。

绘制右连续阶梯函数 `F(t)=首次就绪块数(t)/应到块数`。完整曲线应保留全部首次就绪事件；不以 rank 平均完成度代替按块加权聚合，不以连线绘制预算采样。多个事件有相同 tick 时合并为同一阶梯。显示完整曲线用于复盘，并用独立红色游标标记当前动画时刻，避免用户把未来曲线当作当前已就绪块。

P10、P50、P90、P100 是第一次满足 `累计块数 >= ceil(q × 应到块数)` 的观测时间。这是按块加权的完成比例节点，不是各 rank 总时延的分位数。P90→P100 单独显示，方便辨识长尾。不足阈值显示“未达”；零分母显示无有效任务，不能补零时间或 100%。

## 开始时间的证据

真实发送开始必须来自发送事件或可靠标记。只有接收 flag 日志时，明确标注“真实发送开始未记录”，并列出：

- 首次检查：相关任务最早轮询 start。
- 首块观测：相关数据首次被观察到任意就绪块的检查 end。

这些是两个不同的观测边界，均不是确定的发送开始或实际物理到达瞬间。轮询更早开始但首块更晚出现是正常现象。不要把 P0 定义成确定的网络传输起点。

## 视图与比较范围

1. 不同 group：同一个 rank 或全部 rank 加权汇总；本机复制独立标识。
2. 不同 rank：选择任一 group 或全部 group，保留所有有效 rank 曲线；聚焦某 rank 时高亮，其他 rank 作为背景。
3. 接收/来源 rank：默认按接收 rank 归属。来源 rank 汇总会把多个目的 rank 的相对观察时间合并；跨卡未校准时这只是归一化趋势，不是来源 rank 的发送时钟。
4. 固定同一时间坐标范围，纵轴 0–100%，标记 10/50/90/100% 水平参考线。高亮曲线显示关键点，悬停给出名称、相对 tick、分子和分母。控制页表格提供全部节点的精确值和跳转入口。
5. 曲线继承顶层 group/来源/目的筛选。单独的曲线 group/rank 聚焦状态必须同步到第二屏，并在图上标明口径。导出当前顶层范围内所有 rank×group 节点 CSV，保留缺失值为空。

## 验证与性能

用手工不等量任务验证加权规则，用独立逐块首次观测时间排序复核全部实际组合。检验阶梯单调、最终守恒、相同 tick 合并、阈值前一刻未达、切轮独立、筛选改变分母、未完成输入和无任务输入。

只在 launch、顶层筛选或 rank 口径改变时聚合数据；曲线聚焦和窗口尺寸改变时重画背景。动画每帧复用背景，只更新游标和当前完成度，不能每帧重新解析全量日志。
