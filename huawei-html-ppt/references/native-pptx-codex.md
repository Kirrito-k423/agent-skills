# Codex 原生 PPTX

用户明确要求 PPT/PPTX 文件或已有任务继续修改 PPTX 时，保持文件交付方式。完整 PPTX 与 HTML 同源，均包含封面、目录和正文，目录与页码由数据统一生成。

先读宿主 `presentations/SKILL.md` 及其本地实现和最终验证指南，调用 `load_workspace_dependencies` 获取当期 Node.js、Python 和库路径。使用 `@oai/artifact-tool` 构建、导入、导出与验证，不使用 `python-pptx`、PptxGenJS 或整页截图替代。不得在 Skill 中硬编码本机依赖路径。

1. 读取已装配的 `deck-model.json` 或 HTML 中的 `script#deck-model`，保持封面、目录、正文顺序与总页数，不手工重录事实。
2. 从数据或实际 DOM 几何构造原生文字、表格、节点及连线。坐标只换算一次，默认画布 1280×720。来源和证据口径写入备注。
3. 表格使用原生表格并逐格设置字体、背景、边框、列宽及行高。中文表格无需因图内英文规范而翻成英文，不制造英文断词。
4. 文档或论文原图保持为独立图片，不为可编辑而重画证据。品牌图片保持比例，新增覆盖标注和解释仍为原生对象。
5. 修改整段样式后重新应用 run 级颜色，合并单元格只在左上格写正文，覆盖文字前清空旧内容，避免重复或叠字。
6. 架构图周围留白多时放大图和文字，复杂图可通栏，说明移到下方。表后说明至少留 12px 间隔，不靠缩小字号解决拥挤。
7. 按宿主要求执行开始标记、草稿导出和最终验证，逐页渲染并查看。没有打开 PowerPoint 时不得声称完成原生应用验证。

保留项目生成脚本和模型，后续从同一份数据重新生成。运行依赖、测试输出、项目报告和实际用户数据留在项目目录，不写入 Skill 包。
