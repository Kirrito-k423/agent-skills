# 模板封面与结束页

完整 PPTX 优先直接复用用户指定模板的封面和最后的 Thanks 页。保留背景照片、图片比例、原生文字、品牌标识、母版、布局、主题和页面尺寸。只填写本次题目、作者、版本日期及用户明确提供的部门，不用白底自制页代替有背景的封面，不重画 Thanks 页。

## 本用户的默认资料

用户在 2026-11-06 明确授权将上传模板及这套规则加入 Skill 并推送远端。默认配置为 [default.json](../assets/templates/default.json)，原始模板为 [huawei-light-16-9.pptx](../assets/templates/huawei-light-16-9.pptx)。模板只提供版式，不提供报告的技术事实。

- 默认作者：谭邵杰 t00906153。用户本次指定其他作者时覆盖。
- 封面日期：使用用户指定的版本日期，否则由宿主传入当前客户端日期。该日期不替代正文实验时点。
- 默认选取模板第 1 页作为封面、第 5 页作为 Thanks 结束页，中间配色示例不进入报告。
- 未提供部门或安全级别时，移除相应空字段，不编造内容。
- 将结束页计入总页数，目录仍指向实际正文位置，章节切换导航规则保持不变。

## 原生复用

先用宿主的 `@oai/artifact-tool` 导入、检查模板与目标报告，并用该工具编辑正文或创建需替换的原生内容页。随后用部件复用器合成封面与结束页，避免再次导入导出时改变照片、母版或已有图表数据。

```bash
python scripts/pptx_template_bookends.py \
  --input body.pptx --output complete.pptx \
  --title "报告题目" --author "已确认作者" --date "YYYY-MM-DD"
```

`--template` 可覆盖默认模板；`--department` 仅填写用户已提供的部门。`--replace-slide 6=edited-slide.pptx` 可用宿主生成的完整原生图元替换指定正文页内容，保留目标报告的正文布局和备注挂接，并复制新增图片、图表等依赖；输入应为带明确坐标与样式的内容页，不使用依赖其他布局的空占位符。脚本复制封面与结束页的原生部件及内部依赖，不把整页截图放进 PPTX，不覆盖已有输出。

HTML 预览沿用同一份标题、作者、版本日期及正文数据。封面和 Thanks 的预览可从最终原生模板页本地渲染后嵌入，保留模板视觉；不得把 HTML 截图反向当作原生模板页。

## 验证

对比模板与最终封面、结束页：背景图像字节、母版依赖和原生可见图元保持来源内容，封面仅填写已确认字段。结束页仅继承布局、页面本身没有可见图元时，可将布局图元移入该页，并将继承字体显式绑定到原主题字体，使导出器识别实际内容且避免字体回退；不重画图元，也不叠加两份文字。渲染检查文字是否完整、作者和日期是否清晰、最后一页是否与模板一致。完整报告继续执行原生表格、图表和总页数校验。

包检查只对默认配置中以 SHA256 锁定的授权模板放行，单个模板上限 4 MiB；代码、规则和其他资源仍受原来的 1 MiB 核心预算约束。实际报告、实验数据、渲染缓存及其他 PPT/PDF 不进入 Skill。
