# 性能模型与证据口径

本文件首先用于作者内部核验。成稿选择与核心机制及成果直接相关的公式、实验结论和最小可比条件；不要将下列清单、版本记录、核验过程及每项限制完整搬入专家文章。模型中影响结果成立的关键假设应保留，通常一条图注或一句限定即可。

## 1. 明确指标与分母

定义基线耗时为 \(T_0\)，当前耗时为 \(T_i\)，二者必须覆盖相同工作量与计时边界。

\[
S_i=\frac{T_0}{T_i},\qquad R_i=1-\frac{T_i}{T_0},\qquad G_i=\frac{Q_i}{Q_0}-1
\]

- \(S_i\)：累计加速比；\(R_i\)：耗时降幅；\(G_i\)：吞吐增幅；\(Q\) 为明确单位的吞吐。
- 固定工作量且 \(Q=W/T\) 时，\(G_i=S_i-1\)；工作量变化时不能如此换算。
- “吞吐提高 20%”对应耗时下降约 16.7%，不等于耗时下降 20%。用“从 100 ms 降为 80 ms，下降 20%，加速 1.25 倍”替代“快一倍”等表述。
- 阶段增益 \(T_{i-1}/T_i\) 与累计增益 \(T_0/T_i\) 分列。累计同条件比值可连乘，不可把各阶段百分比直接相加。
- 相对竞品的吞吐比 \(Q_{\rm target}/Q_{\rm reference}\) 和耗时比 \(T_{\rm target}/T_{\rm reference}\) 互为倒数仅在等工作量时成立。写清“0.7 倍”是哪一个。

## 2. 从局部瓶颈估计端到端上限

### Amdahl 模型

若可优化部分占基线墙钟时间的比例为 \(f\)，局部加速为 \(s\)，新增开销相对基线为 \(h\)，且各部分可串行分解，则：

\[
T_{\rm new}=T_0\left((1-f)+\frac{f}{s}+h\right),\quad
S=\frac{1}{(1-f)+f/s+h},\quad
S_{\rm ideal}\leq\frac{1}{1-f}\;(h=0,\ s\rightarrow\infty)
\]

给出可复算例子：**以下为教学假设，非实验结果。** 若基线 100 ms，目标段占 60%，优化到原来的三分之一，新增开销 5 ms，则新耗时 65 ms、加速约 1.538 倍；完全消除目标段且无新增开销的理想界为 2.5 倍。

只有无重叠、同一范围的比例才能进入该式。Profiler 的所有 kernel duration 之和、不同 rank 的时间和或 p50 之和通常不是墙钟分解；多流并发要先画时间线/DAG，找关键路径。对多个不重叠部分可用 \(1-\sum f_j+\sum f_j/s_j+h\)，不能重复扣除同一段开销。

### 计算、搬运与依赖下界

\[
T_{\rm lb}=\max\left(\frac{F}{P_{\max}},\frac{B}{BW_{\max}},D\right)
\]

其中 \(F\) 为 FLOP，\(P_{\max}\) 为相同精度的算力上界，\(B\) 为该存储层必须搬运的字节，\(BW_{\max}\) 为对应带宽上界，\(D\) 为串行依赖的时间下界。\(T_0/T_{\rm lb}\) 只给宽松加速上界，不是承诺。不同存储层、网络链路或不能重叠的阶段应分别建模。

以同 shape/dtype/layout 微基准得到的有效带宽/吞吐替代峰值可作**可达估计**，但它不再是严格下界。注明测量形态、调用开销与数据是否驻留缓存；禁止只用硬件峰值比例折算实际性能，或假设双 die 一定线性加速。

### 异步与流水

\[
T_{\rm serial}=T_A+T_B,\qquad T_{\rm ideal\ overlap}\geq\max(T_A,T_B)
\]

\[
T_{\rm pipe}(n)\approx \sum_j t_j+(n-1)\max_j t_j+T_{\rm extra}
\]

这里 \(n\) 是等大小批次数，\(t_j\) 是固定阶段服务时间；\(\sum_j t_j\) 已计入首批穿过流水线的时间，\(T_{\rm extra}\) 是尚未计入的额外开销，不再重复加填充/排空时间。仅在阶段独立、缓冲充足、资源无冲突时使用理想重叠；H2D/D2H 与计算争用带宽、队列回压、rank 长尾、调度和同步都会增大实际耗时。把“减少同步次数”进一步推导为关键路径缩短，不能直接等同收益。

## 3. 显存与并发容量

按同一时刻的独占物理分配预算建模：

\[
M_{\rm peak}=\max_t\left[M_{\rm weights}(t)+M_{\rm optimizer}(t)+M_{\rm gradients}(t)
+M_{\rm activation}(t)+M_{\rm KV}(t)+M_{\rm workspace}(t)+M_{\rm other}(t)\right]
\]

说明每项是已分配物理显存、逻辑用量还是池预留；共享 Buffer 不重计，allocator 的 reserved 与 allocated 不相加。\(M_{\rm other}\) 包括不重叠计数的运行时、残留、碎片与安全余量。不要相加发生在不同时刻的各项峰值。

\[
M_{\rm KV,budget}=M_{\rm allowed}-M_{\rm nonKV,peak}-M_{\rm margin}
\]

对标准 K/V 注意力，可从**每设备实际存放**的层数和 KV head 数估计：

\[
b_{\rm token}=2L_{\rm local}H_{\rm KV,local}d_{\rm head}b_{\rm element},\qquad
N_{\rm tokens}\leq\left\lfloor\frac{M_{\rm KV,budget}}{b_{\rm token}}\right\rfloor
\]

该式忽略页块对齐、元数据和碎片，只是容量上界。明确 TP 下 KV head 是否复制，不能默认除以 TP；混合 GDN、MLA、量化 KV 或滑窗模型按其真实状态布局另算。并发由长度分布决定，平均长度的商只是估计；长尾场景用分位数或请求级仿真校核。

显存优化先说明“能否运行”，再测因并行度/批量改变带来的性能净收益。不能把从 OOM 到可运行画成有限加速比。

## 4. 实验口径与因果

| 工作底稿需核对的项 | 核验内容 |
|---|---|
| 硬件 | 设备型号、主机/卡/die 数、拓扑、资源是否独占 |
| 软件 | 仓库 commit、编译器、运行时、图模式/eager、关键开关 |
| 负载 | 模型、shape、dtype、layout、序列分布、并发、数据与随机性 |
| 计时 | 起止点、host/device、预热、同步方式、重复次数、聚合统计 |
| 正确性 | 参考实现、数值阈值、异常值处理、覆盖输入、结果 |
| 系统 | 多 rank 一致性、稳定运行窗口、失败/重试与质量约束 |

host 计时需确保相关设备工作完成，但在热循环每步强插同步会改变流水；说明同步放置与扰动，优先采用适合执行模型的事件或 profiler。长尾给 p95/分布，误差线说明是分位数、标准差还是置信区间。没有重复样本就不伪造误差线。

累积阶段链能说明最终方案的边际变化，不能独立证明每个机制的因果贡献。存在多项共同变化时标注混杂，补单因素或组合消融；硬件/数据/统计口径变化时分组画图。

对异步 RL，用 \(Q_{\rm useful}=N_{\rm accepted}/T\) 记录实际进入训练的有效样本或 token，写明过滤标准；区分采样计划、下发、完成和最终进入 batch 的分布。吞吐增加不能代替 reward/评测及策略滞后的检查，entropy 变化也不能单独证明两分布一致。

## 5. 证据与结论边界

| 已有证据 | 可以说 | 尚不能说 |
|---|---|---|
| 源码/设计/理论模型 | 存在某路径、估计某上限 | 真实硬件已获得收益 |
| host 测试/编译 | host 行为或编译通过 | NPU 正确、多 rank 同步正确 |
| 单算子实测 | 指定输入的数值与局部性能 | 整网同幅度提升 |
| 模块/多 rank 实测 | 指定边界与配置已验证 | 未测规模或长跑稳定 |
| 硬件端到端与质量检查 | 指定负载的总体收益 | 所有模型、序列、设备通用 |
| 历史文档/截图 | 原文报告的数值与结论 | 本次独立复现 |

内部逐项确认结论不超出实际证据。正文用实验方法、关键结果及必要的适用范围收束，无需逐项列出证据层级、未测项或核验清单，也不要求把所有层级机械跑一遍。
