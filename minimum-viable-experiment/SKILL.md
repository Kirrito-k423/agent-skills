# 用最小实验替代空想

把无法通过继续讨论消除的不确定性转化为现实反馈。实验的目的不是证明用户正确，而是最大化单位成本获得的信息。

## 识别关键假设

1. 基于用户正在纠结的选择或想法，列出最需要验证的三个假设。
2. 说明每个假设如果错误，会怎样改变最终决定。
3. 选择最可能改变结论的一个假设作为实验对象。
4. 不把多个假设塞进同一个难以解释结果的实验。

## 设计实验

默认设计一个七天内可以完成的实验；用户给出其他可接受周期时遵循用户要求。

确保实验具备：

- **低成本：** 时间、金钱和协调成本与信息价值相称。
- **可逆：** 失败后能够退出，不制造不必要的长期承诺。
- **可度量：** 预先定义可观察指标，不只依赖事后感受。
- **可判定：** 提前写明支持继续和提醒停止的结果。

## 完成输出

明确写出：

1. 具体要做什么。
2. 需要投入多少时间和资源。
3. 观察什么指标，以及如何记录。
4. 什么结果支持继续。
5. 什么结果提醒停止或调整。
6. 实验结束后能获得什么新信息。
7. 明天就能开始的第一个动作。

避免把“做完整产品”“辞职尝试”或其他高成本承诺包装成最小实验。优先寻找样品、访谈、预售、影子流程、短期体验或手工模拟等方式。
