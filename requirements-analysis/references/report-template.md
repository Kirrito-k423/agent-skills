# 需求分析报告模板

填写报告时删除说明性提示。某章节不适用时，保留裁剪理由和由此引入的风险，不要静默删除。

全文采用开发前语态：写“应、必须、拟采用、计划验证”，不写“已实现、已通过、已上线”。
