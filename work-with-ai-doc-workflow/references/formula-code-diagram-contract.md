# 公式、源码与计算图契约

文章包含公式、源码摘录、伪代码推导、tensor 图、cache 图或 state 更新图时阅读本契约。

## 先完整分析，再渐进披露

在后台建立对象账本：

| 对象 | 公式符号 | 源码标识符 | 生产者 | shape / dtype | 消费者 | 生命周期与状态 |
|---|---|---|---|---|---|---|
| 示例输入 | `h_t` | `hidden_states` | 前一层 | `[B,S,D]`、BF16 | Q/K/V 投影 | 临时激活、实际 tensor |

把对象分为参数或权重、临时激活、cache 或循环状态、控制值或超参数、只用于解释的代数视图。

账本用于保证分析正确，不要求原样刊登。正文只引入回答当前问题所需的对象，但每个已出现对象都必须有来源、去向和明确身份。

## 公式解释

1. 先用自然语言说明公式要回答什么，再展示符号。
2. 在首次使用处定义符号和关键轴，并给出足以建立直觉的 shape。
3. split、concat、reshape、transpose、normalization、位置编码、mask、scale、cache 读写或输出投影会改变语义或 shape 时，不能静默跳过。
4. 源码复用同一变量名表示多个阶段时，为解释阶段使用不同名称。
5. 非平凡 MatMul 或 `einsum` 说明收缩轴与输出 shape。
6. 语义公式与优化实现不同时，分别展示并解释等价关系。
7. 对矩阵吸收、融合、view、expand、量化或 decode 优化，说明哪些 tensor 实际物化、共享存储或只存在于代数解释中。

公式密度让读者需要频繁回看符号表时，优先拆解成小例子、shape 变化或分步公式，而不是继续堆符号。

## 源码与伪代码

- 固定仓库、revision、文件、符号和行号范围。
- 摘录范围围绕当前结论，不为“完整”复制整段实现。
- 允许使用 `...` 省略日志、监控、参数校验和无关兼容样板，并在旁边说明省略内容。
- 不得省略会改变输入、分支、shape、通信、cache/state、内存生命周期或输出的代码。
- fused operator 需要说明与当前结论有关的逻辑子操作及输入输出契约。
- 区分 prefill、decode、training、兼容路径和优化 kernel；它们物化不同对象时不能混写。
- 紧邻代码建立公式符号与源码变量映射，不把查找工作留给读者。

## 点线计算图语法

计算图解释 tensor 计算，不把所有内容画成通用流程框。

### 节点

- **圆形**：activation 或 tensor，旁边标注名称与 shape。
- **双边框或带 badge 的圆形**：跨 token、chunk 或 layer 存活的 cache/state tensor。
- **方形或圆角矩形**：RoPE、MatMul、RMSNorm、Transpose、Reshape、Split、Concat、Softmax、Mask、Quantize、Gather 等具体算子或模块。

权重、axis、scale、head 数、group 数、top-k 和 permutation 等放在边标签，不画成算子。

### 边与布局

- 实线箭头表示 activation 数据流。
- 虚线只表示控制、mask、cache 更新或明确标注的代数等价路径。
- 边不能静默改变 shape；加入对应算子节点或明确变换标签。
- 选择一个主方向，平行分支对齐，减少交叉，保证箭头方向和端口稳定。
- 颜色只强化语义，不能成为区分 Q/K/V、cache 或 state 的唯一方式。
- 图注说明这是实际运行路径、语义展开，还是代数等价图。

## MLA 专项边界

解释 MLA 时，根据所选运行路径交代适用的核心对象：输入 activation、Q 下投影与归一化、Q 的非 RoPE 与 RoPE 分支、联合 KV 下投影、压缩 KV latent、解耦 RoPE K、KV 归一化、语义 K/V 上投影、score、scale、mask、Softmax、value 聚合、输出投影，以及实际 cache。

正文必须明确回答：**哪些 Q/K/V 对象只在数学上存在，哪些实际物化，decode 真正缓存哪些 tensor。** 不相关路径可以不展开，但要说明当前解释覆盖 prefill、decode、training、兼容或优化路径中的哪一个。

## 覆盖与视觉审计

1. 将正文中出现的每个对象映射到 tensor 节点、算子节点、边标签或明确的图注省略。
2. 拒绝无解释的公式符号、源码变量、孤立节点、静默 shape 变化和缺失输出。
3. 确认 cache/state 生命周期与临时激活视觉可区分。
4. 在原始尺寸阅读 SVG 与 PNG，检查文字、shape、箭头、重叠和分支对齐。
5. 图注注明固定源码 revision，并说明物理、语义或代数属性。
6. 最后从读者角度判断：图是否比相邻文字更快解决问题；如果没有，删除图或重画，而不是为了覆盖率保留。
